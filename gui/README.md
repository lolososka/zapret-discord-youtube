# Zapret Control Center

> [!NOTE]
> Это неофициальная GUI-оболочка для
> [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
> Проект не аффилирован с Flowseal и не является официально одобренной сборкой.

Графическая оболочка для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
от Flowseal. Один `ZapretGUI.exe` заменяет и запуск стратегий двойным кликом по `.bat`,
и консольное меню `service.bat`.

Программа **не является** новым способом обхода блокировок. Обход как выполнял, так и выполняет
`bin\winws.exe` + драйвер WinDivert из проекта [zapret](https://github.com/bol-van/zapret),
а сами стратегии — это те же `.bat`-файлы Flowseal, которые лежат рядом. Оболочка их читает,
разбирает и запускает.

---

## Что умеет

**Панель**
- Большой силовой диск: запуск и остановка обхода одним кликом, живое состояние
  (остановлен / запуск / активен / ошибка), время работы.
- Осциллограф пакетов в секунду и скорости по сетевым интерфейсам, PID и потребление
  памяти `winws.exe`.
- Быстрые переключатели: игровой фильтр, проверка обновлений, автозапуск обхода.
- Безопасное обновление всей portable-сборки из релиза форка: строгий TLS, двойная
  сверка SHA-256, отдельный helper для замены запущенного EXE и автоматический откат,
  если новая версия не смогла инициализироваться.
- Проверка доступа: реальные запросы к YouTube, googlevideo, Discord API/CDN/Media и Google
  с замером задержки.

**Стратегии**
- Все профили из папки, разобранные из `.bat`: понятное название и описание обычными
  словами; технический разбор и полная строка аргументов — в окне «Подробнее».
- **Автоподбор**: программа сама прогоняет все профили, на каждом проверяет YouTube, Discord
  и Google и показывает, какие реально работают и с какой задержкой. Рабочую стратегию нельзя
  угадать заранее — она зависит от провайдера, поэтому перебор автоматизирован.
- Избранное со звёздочкой и автоматическая отметка «работала у вас» для профиля,
  продержавшегося дольше минуты.
- Поиск и фильтры, включая фильтр по избранным.
- Рабочую стратегию можно сменить без ручной остановки: GUI перезапустит обход,
  а если новый профиль не поднимется — вернёт предыдущую стратегию и GameFilter.
- «Свои сайты» — безопасный редактор пользовательских списков: домены для обхода,
  домены-исключения и IP/CIDR-исключения. URL и международные домены нормализуются,
  ошибки формата показываются до сохранения, служебные базы не затрагиваются.
  Несохранённые изменения отмечаются в интерфейсе и защищены подтверждением при закрытии.
- Установка и удаление службы Windows — тот же порядок команд `sc`, что и в `service.bat`.

**Телеграм**
- Находит, запускает и останавливает [TgWsProxy](https://github.com/Flowseal/tg-ws-proxy) —
  отдельную утилиту Flowseal: локальный MTProto-прокси на `127.0.0.1:1443`. Сам zapret тут
  не помогает, потому что Telegram Desktop ходит по нестандартным портам.
- Утилита в поставку не входит и не скачивается автоматически; программа ищет её рядом с собой,
  в автозагрузке, на рабочем столе и в «Загрузках», либо принимает указанный вручную путь.
- Готовит ссылку `tg://proxy` для настройки Telegram в один клик.

**Диагностика**
- Перенесены все проверки из `service.bat`: Base Filtering Engine, системный прокси,
  TCP timestamps, Adguard, службы Killer / Intel Connectivity / Check Point / SmartByte,
  наличие `WinDivert64.sys`, активные VPN, шифрованный DNS, записи YouTube в `hosts`,
  конфликтующие обходы (GoodbyeDPI, discordfix_zapret, winws1/2) и «осиротевшая» служба WinDivert.
- Проблемы, которые можно устранить, чинятся кнопкой прямо из списка.
- Обновление списка IP, проверка `hosts`, проверка новой версии.

**Журнал**
- Живой вывод `winws.exe` с подсветкой по уровню, фильтрами, поиском, липкой автопрокруткой,
  копированием и сохранением в файл. Дублируется в `%APPDATA%\ZapretGUI\zapret-gui.log`.

**Настройки**
- Пять акцентов оформления, режим уменьшенных анимаций.
- Автозапуск с Windows, старт свёрнутым в трей, автоматическое включение обхода.
- Игровой фильтр (выкл / TCP+UDP / TCP / UDP), режим IPSet (список / выключен / любые адреса),
  замена активных fake-пакетов для Discord и игр.

Плюс значок в трее, меняющий цвет по состоянию (серый — выключен, янтарный — запускается,
акцентный — работает, красный — упал), автоперезапуск обхода при падении `winws.exe`
(до трёх попыток за 10 минут), единственный экземпляр приложения и горячие клавиши
`Ctrl+1…6`, `Ctrl+R`, `Esc`.

**Шрифт и оформление**
Интерфейс использует системные Segoe UI Variable / Segoe UI; цифры — моноширинные.

## Установка

Готовая сборка находится в
[последнем GitHub Release](https://github.com/lolososka/zapret-discord-youtube/releases/latest).

1. Скачайте ZIP с `win-x64` в названии и при желании сверьте его SHA-256 по `SHA256SUMS.txt`.
2. Распакуйте архив целиком в новую папку.
3. Запустите `ZapretGUI.exe`. Программа запросит права администратора: без них WinDivert не поднимется.

В portable-архив уже входят GUI, `bin`, `lists`, `utils`, стратегии `general*.bat` и `service.bat`.
Отдельный `ZapretGUI.exe` в релизе нужен только тем, кто вручную обновляет уже существующую
папку оригинального zapret.

`.bat`-файлы удалять нельзя — именно из них читаются стратегии.

Если `bin\winws.exe` не найден, приложение скажет об этом при старте и покажет, где искало.

## Сборка из исходников

Нужен .NET 8 SDK.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт публикует self-contained single-file `win-x64`. В составе форка он автоматически
копирует `ZapretGUI.exe` в корень zapret; при отдельной сборке укажите
`-Target "путь\к\zapret"` или используйте `-NoDeploy`. Путь к SDK при необходимости
можно передать через `-Dotnet "путь\к\dotnet.exe"`.

## Как это устроено

```
ZapretGui/
  Core/          логика: разбор .bat, запуск процесса, служба, диагностика, метрики
  Themes/        палитра, типографика, анимации, стили контролов, иконки
  Controls/      силовой диск, фоновая аврора, тосты, присоединённые анимации
  Views/         шесть страниц
  MainWindow     каркас окна: свой хром, нав-рейл, переходы, трей
docs/
  design-spec.md утверждённая спецификация оформления и движения
```

Ключевые места:

- `Core/Strategy.cs` — разбор `.bat`: склейка строк по каретке, подстановка `%BIN%`, `%LISTS%`,
  `%~dp0`, `%GameFilterTCP/UDP%`. Отдельно обрабатывается `^!` — в `general (FAKE TLS AUTO).bat`
  каретка экранирует восклицательный знак, а не переносит строку.
- `Core/BypassController.cs` — единственный владелец дочернего `winws.exe`. Падение процесса в первые
  2.5 с считается ошибкой запуска и показывает захваченный вывод. При закрытии приложения гасится
  только свой процесс: обход, поднятый службой, продолжает работать.
- `Core/ZapretServiceManager.cs` — `sc.exe` вызывается напрямую, без `cmd.exe`, иначе оболочка
  переинтерпретировала бы кавычки и `!` внутри `binPath`.
- Порядок стратегий воспроизводит меню `service.bat` (PowerShell там сортирует имена файлов,
  дополняя числа нулями, поэтому `(ALT)` идёт перед `(ALT2)`, а `(FAKE TLS AUTO ALT)` — перед
  `(FAKE TLS AUTO)`).

## Ограничения, о которых честно

- Счётчик пакетов и скорости — общесистемный, по сетевым интерфейсам. Отделить трафик, прошедший
  через WinDivert, изнутри приложения нельзя, поэтому в интерфейсе он и подписан как трафик
  интерфейса.
- Оболочка не улучшает и не ухудшает сам обход. Автоподбор ускоряет перебор, но рабочую
  стратегию по-прежнему определяет ваш провайдер, а не программа.
- **Сменить страну или IP оболочка не может.** `winws` только искажает пакеты, чтобы DPI не
  распознал домен; маршрут и внешний адрес остаются провайдерскими, и сайты видят ваш реальный IP.
  Показать другую страну способны только VPN или прокси, которые действительно ведут трафик через
  чужой сервер. Поэтому вместо неработающего переключателя «страна» на «Диагностике» стоит
  честная карточка «Как вас видят сайты» — она показывает фактический IP, страну и провайдера.
- Автообновление рассчитано на готовую portable-сборку. В git-клоне оно намеренно
  отключено: исходники следует обновлять через Git. Версии до `1.11.0` ещё не содержат
  updater, поэтому первый переход на `1.11.0` выполняется скачиванием нового ZIP вручную.

## Синхронизация форка

GitHub-репозиторий автоматически проверяет `Flowseal/zapret-discord-youtube` каждые 6 часов.
Новые изменения сначала применяются к временной копии, затем на Windows выполняется публикация GUI.
Только после успешной проверки бот создаёт отдельный коммит вида
`chore(upstream): sync Flowseal ...` и отправляет его в `main` без `force`.
Затем та же задача собирает portable ZIP, отдельный EXE и `SHA256SUMS.txt`, проверяет содержимое
архива и публикует GitHub Release, привязанный к точным ревизиям Flowseal и форка.

Папки `gui/` и `.github/`, а также корневые `README.md` и `.gitignore` принадлежат этому форку
и при синхронизации не заменяются. Конфликт в остальных файлах останавливает задачу
без коммита и требует ручного разрешения.
Синхронизацию также можно запустить вручную на странице
[Sync Flowseal upstream](https://github.com/lolososka/zapret-discord-youtube/actions/workflows/sync-upstream.yml).

Это обновляет репозиторий и выпускает новую готовую сборку. Начиная с GUI `1.11.0`,
установленная portable-копия обнаруживает как новую версию оболочки, так и новый
Flowseal commit в релизе форка. Перед заменой ZIP проверяется по `SHA256SUMS.txt`
и digest GitHub API, пользовательские списки/флаги/активные fake-пакеты сохраняются,
а прежняя папка остаётся рядом как резервная копия. Если новая версия не подтвердит
успешный запуск, helper автоматически вернёт прежнюю папку.
